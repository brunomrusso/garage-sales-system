Seguranca

Frontend

  • Token JWT armazenado em localStorage
  • Verificacao de role (admin/cliente/master)
  • Protecao de rotas com React Router
  • Context API para estado de autenticacao

Backend

  • CORS configurado para dominios especificos
  • Hash de senhas com bcrypt
  • Tokens JWT com expiracao (24h)
  • Validacao de inputs com Pydantic
  • Multi-tenant isolation por empresa_id
